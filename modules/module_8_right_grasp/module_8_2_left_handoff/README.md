# 模块 8-2：Right Handoff

## 职责

右手直接从已经持件的左手接取工件，并撤离到后续放置准备区域。

## 输入

必须传入 Module 5-2 本轮生成、且已经用于移动左手到交接位的 ICP
`result.json`。Module 8-2 不会自动选取“最新结果”，以免误用旧轮次数据。
该结果默认由 Module 5-2 调用 `auto_head_d435_mask.py` 自动分割生成；Module
8-2 只消费结果，不再次拍摄或分割。

## 流程

```text
实时左 TCP × ICP 左 TCP-工件关系重建工件位姿
→ Planner MoveL 到尾部预抓取位
→ 到位后再次重建工件位姿
→ Planner MoveL 微调到最终抓取位
→ 右夹爪闭合
→ 左夹爪异步抢占打开并确认真实运动/到位
→ 右手 MoveL 上升 3 cm
→ 右手 MoveL 后退 8 cm
→ 右手 MoveJ 到 Module 9 上方准备位
→ 左臂 MoveJ 回中间位
```

工件1使用在统一高位交接中心重新记录的现场右手示教位建立名义工件—右TCP关系；
ICP 补偿、左夹爪释放门禁和 Module 9 上方准备关节角均保留自 V2 已验证实现。

## 独立执行

```bash
cd /home/dainanjun/Public/Parm_Grasp_Place_Loop

python3 modules/module_8_right_grasp/module_8_2_left_handoff/main.py \
  --result output/reversed_head_pose_d435/<timestamp>/result.json
```

需要恢复逐步运动确认时加 `--require-confirmation`。

Module 8-2 必须在 Module 5-2 成功结束后立即运行；若工件在左夹爪中发生
滑动，原 ICP 刚性关系失效，禁止继续交接。

## 工件2

总控带 `--workpiece 2` 时，Module 8-2 选择本目录
`workpiece_2_runtime/` 的工件2交接执行器和配置，使用 Module 5-2 同轮 ICP
结果验证左手实时持件状态与交接中心 `body_base [0.42, 0.10, 0.25]`。

总控进入本模块前、右手预抓取/抓取、释放后工件系撤离、右手放置准备位和
左手较高回程位全部读取 `modules/reverse_grasp_handoff_positions.toml`。其中第二类
右臂预交接准备位与预抓取位统一为 `[173.9519, 50.8063, -79.5218,
85.0397, -25.3112, 4.5552, 79.6344]`。该右手目标只用于工件2。
模块会把总控速度倍率传入工件2执行器，并在到位标记中写入工件类型、profile
版本和实际目标关节角。

该分支仅执行：右手尾部接取、右夹爪闭合、左夹爪释放、右手撤离到 Module 9
准备位、左臂回中间位。它不会执行右手最终放置；最终放置仍由后续模块调度。
模块运行时不调用 `tests/reversed_head_observation_2/full-execute`，因此不会出现
总控与独立测试同时控制同一动作的情况。

## 工件1高位交接

工件1只与工件2共用左手观察/交接中心和左手高位回程，不复用工件2的任何右手
交接关节位。总控仍从工件1原安全预交接入口进入。当前右手高位交接示教位为
`[171.9469, 51.0013, -71.8698, 90.78, -26.4565, -8.5611, 70.5734]`；
它已经在新中心 `[0.42, 0.10, 0.25]` 附近完成现场示教，因此运行时不再重复施加
旧中心到新中心的 TF 变化量，只继续使用实时 ICP 做最终补偿。旧低位示教数组在
代码中保留为注释以便追溯。接取时先根据本轮实时工件 TF，沿工件坐标系 `-X`
平移 `0.05 m` 生成预交接目标并 MoveL 到位，再 MoveL 到实时 ICP 修正后的示教
交接目标。第一类显式使用 `0°` 名义工件倾角，与 Module 5-2 的固定交接朝向一致；
不会再被旧流程的 `5°` 基准额外修正。

交接完成后，工件1回到自己的原放置准备位
`[30.4353, 23.8637, 0.5905, 66.3409, -62.0439, -64.3304, 25.7149]`；
第二类继续从自己的 profile 使用 `[102.2483, 21.8477, -87.2013, 83.4439,
-147.2882, -32.2943, -66.0196]`，两条配置链互不引用。由于这是关节标定目标，
第一类以七轴反馈作为最终到位门禁，
不再用本地 URDF FK 与规划器实时 TF 的系统偏差阻断流程。
