# 工件 1：STL 与工件坐标系

工件 1 的正式坐标系名为 `workpiece1_stl`。当前阶段它与
`workpiece_1.stl` 的原生数值坐标系完全相同，不使用额外旋转或平移：

```text
T_stl_workpiece1 = I
O_workpiece1 = O_stl = (0, 0, 0) m
X_workpiece1 = +X_stl
Y_workpiece1 = +Y_stl
Z_workpiece1 = +Z_stl
```

这是右手坐标系，满足 `X+ x Y+ = Z+`。

## 原点说明

原点严格使用 STL 顶点坐标的数值原点 `(0,0,0)m`，**不是** STL 包围盒中心。
当前 STL 的包围盒中心约为 `(0.000062, -0.000010, 0.010650)m`，因此不要把
包围盒中心误当作本配置的工件原点。

`workpiece_1.stl` 与上一级目录中的
`welding_up_side_1118_only_2_small_screws_removed.stl` 的 SHA-256 相同；前者是
工件 1 的固定引用副本。
