# 工件 2：STL 与配置文件的坐标正方向

`workpiece_2.stl` 的原始坐标轴方向，与 `workpiece2_top_axes.json` 中定义的工件坐标轴方向**不相同**。

STL 只保存三角面顶点的数值坐标；它不包含“工艺 X/Y/Z 正方向”的业务定义。工件坐标系是根据 Top 视图中约定的方向，使用 STL 坐标表示出来的。

| 工件配置轴正方向 | 在 STL 坐标系中的向量 | Top 图中的显示方向 |
| --- | --- | --- |
| X+ | `[-1.0, 0.0, 0.0]` | 向左 |
| Y+ | `[0.0, -1.0, 0.0]` | 向下 |
| Z+ | `[0.0, 0.0, 1.0]` | 指向观察者（屏幕外） |

因此，转换关系为：

```text
X_workpiece = -X_stl
Y_workpiece = -Y_stl
Z_workpiece =  Z_stl
```

矩阵形式（列向量）为：

```text
[X_workpiece]   [-1  0  0] [X_stl]
[Y_workpiece] = [ 0 -1  0] [Y_stl]
[Z_workpiece]   [ 0  0  1] [Z_stl]
```

该变换为右手坐标系：`X+ × Y+ = Z+`。

## 工件中心点与原点

工件中心点正式定义为 STL 模型包围盒的中心，并作为工件坐标系原点：

```text
O_workpiece = (0.0, 0.0, 0.0)
```

该模型的 STL 包围盒范围为 `X=[-55.5, 55.5]`、`Y=[-43.7599, 43.7599]`、`Z=[-31.0651, 31.0651]`，因此其包围盒中心恰好位于 STL 数值原点。此处的“中心点”是模型包围盒中心，不等同于材料重心或夹具定位点。

使用 STL 顶点、法向或位姿数据时，应先确认其处于 STL 坐标系还是工件配置坐标系，避免将两个方向直接混用。
